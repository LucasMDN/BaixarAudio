# BaixarAudio
Programa para baixar audio no YouTube

Proposta:
- Tela que possa informar a URL do vídeo e ouvir o que tem, caso deseja poderá fazer o download;
- Criar uma lista de URL que poderá ser feito o download e indicar onde esses arquivo deverão ser salvos;
- Pegar as letras das músicas
